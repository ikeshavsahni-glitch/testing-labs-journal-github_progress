| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |The CPU processes instructions, performs calculations, and controls the computer’s operations. |Clock speed (GHz), number of cores, threads, and cache memory.  |
| RAM |RAM temporarily stores data and programs that the CPU is currently using for fast access. |Capacity (GB), speed (MHz/MT/s), and type (e.g., DDR4 or DDR5).  |
| Storage |Storage devices permanently save data, files, programs, and the operating system even when the computer is turned off.  |Capacity (GB/TB), type (HDD or SSD), and read/write speed. |
| Motherboard |The motherboard connects all computer components and allows them to communicate with each other. |Form factor (ATX, Micro-ATX), chipset, CPU socket type, RAM slots, and expansion slots. |
| Power Supply |he power supply unit (PSU) converts electricity from the wall outlet into power that the computer components can use. |lower output (watts), efficiency rating (80 Plus), and connector types.  |
| Cooling |The cooling system removes heat from computer components to prevent overheating and maintain stable performance. |Cooling type (air or liquid), fan size, airflow, and cooling capacity |
