# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware is the physical parts of a computer that you can see and touch. Examples include the keyboard, mouse, monitor, printer, hard drive, and motherboard. Hardware works together with software to perform tasks, process data, store information, and help the computer operate properly and efficiently every day

## Explain Software
Write **at least 50 words** explaining what software is.
Software is a set of programs and instructions that tell a computer what to do. Unlike hardware, software cannot be touched. Examples include operating systems, web browsers, games, and word processors. Software helps users perform tasks, manage files, communicate, and use the computer effectively every day.
